# 从泛函观点看机器学习

机器学习最终常常要回答“函数怎样变化”的问题。模型是函数，损失是在评价函数，训练是在函数族里寻找更好的函数，泛化则关心这种寻找过程在新数据上是否仍然稳定。

分析视角提供的是研究极限、收敛、连续性、稳定性和优化过程的语言。它让我们不只会写出训练目标，还能进一步讨论目标是否有解、迭代是否收敛、误差是否可控、函数空间里哪些近似是可靠的。

这里的目录已经按新的结构合并：凸分析不再单独成章，而是并入“最优化理论和变分法”；变分法也不再作为独立目录，而是和优化理论放在一起讲。这样更符合学习路径：先把“怎样找好解”这一组问题放到同一个地方，再进入函数空间、概率积分和连续演化这些分析视角。
