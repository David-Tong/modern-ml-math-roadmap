# 一些补充路线

有些数学工具不是所有机器学习方向都必须先学，但一旦进入特定问题，就会变得非常关键。比如图结构、组合对象、对称性约束、编码、随机过程、信息论或统计物理方法，都常常出现在某些专门研究路线里。

补充路线的作用不是再开一条庞大的主线，而是帮助读者在遇到具体问题时知道该补哪些工具。它更适合作为问题驱动的工具箱：读到图、集合、对称性、离散状态或某个专门理论方向时，再回来选取需要的部分。
