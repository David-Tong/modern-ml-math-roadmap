# 抽象代数：研究结构的语言

本章用于介绍抽象代数的基本概念：集合上的运算、结构、同态、商结构、群、环、域、作用和不变量。这里不展开伽罗华理论，也不细讲方程根式可解性的专门理论；重点是帮助读者先理解抽象代数研究的是什么，以及它用什么视角看数学。

抽象代数关心的不是某一类具体数字本身，而是对象之间可以怎样组合、怎样变换、哪些规则在这些操作中保持不变。换句话说，它研究的是结构。整数、矩阵、多项式、函数、对称变换、置换，看起来是很不一样的对象；但如果它们背后有相似的运算规则，就可以放进同一种代数语言里理解。

## 计划写的内容

### 一、从结构开始：抽象代数研究什么

这一节先说明抽象代数的基本视角：它不是把数学对象只看成可计算的数值，而是把它们看成带有规则的系统。抽象代数会问：这里有哪些对象？对象之间允许做什么运算？这些运算满足哪些规则？不同对象之间有没有保持这些规则的对应关系？

在本章中，结构可以先粗略理解为：

> 结构 = 对象集合 + 运算或关系 + 这些运算或关系必须满足的规则。

例如，整数不只是一个个数；当我们关心加法和乘法时，它形成一种代数结构。平面旋转也不只是几何动作；当我们关心“两个旋转能否合成”“有没有不做任何事的旋转”“每个旋转能否撤销”时，它也形成一种代数结构。抽象代数的任务，就是把这些表面不同、规则相似的系统放到统一框架中研究。

这一节的目标是让读者先建立一个判断：抽象代数不是一套凭空出现的公理游戏，而是一种看数学的方式。它把注意力从“对象长什么样”转移到“对象之间的操作规则是什么，以及哪些规则在变化中被保留下来”。

### 二、集合、关系与运算

这一节介绍抽象代数最底层的积木：集合、元素、关系、等价关系和二元运算。重点不是形式符号本身，而是理解“在一个集合上定义一种运算”是什么意思，以及封闭性、结合律、交换律、单位元和逆元这些条件为什么重要。

这些概念会为后面的群、环、域和商结构做准备。读完这一节，读者应能看懂一个代数结构通常由“对象集合 + 运算规则 + 满足的公理”组成。

### 三、群：描述可逆变换的语言

这一节介绍群的基本概念：群运算、单位元、逆元、子群、循环群、置换群和群的例子。这里会把群理解成“可逆操作的集合”，而不是抽象符号游戏。

目标是让读者理解为什么旋转、平移、置换、重标号这类变换都可以用群描述。机器学习中谈到对称性、等变性和不变量时，群通常就是背后的基础语言。

### 四、环与域：把加法和乘法组织起来

这一节介绍环和域的基本概念。群通常只组织一种运算，而环和域同时组织加法与乘法，因此更接近我们熟悉的整数、有理数、实数、多项式和矩阵运算。

这里会说明环、域、零元、单位元、可逆元、整环、多项式环等基础概念，但不展开伽罗华理论。目标是让读者理解：为什么很多数学对象虽然长得不像普通数字，却仍然能进行类似加法和乘法的结构化运算。

### 五、同态、同构与商结构

这一节介绍抽象代数里非常核心的一组观念：怎样在不同结构之间建立保持运算的映射。同态强调“映射以后运算关系仍然成立”，同构强调“两个结构本质上一样”，商结构则描述“把某些元素视为等价以后得到的新结构”。

这些概念能帮助读者理解代数为什么关心结构而不是表面形式。机器学习里做表示学习、压缩、抽象状态建模或研究不变量时，经常会遇到类似的思想：不同表示可以不同，但关键结构应被保留下来。

### 六、作用、对称性与不变量

这一节介绍群作用、轨道、稳定子、不变量和等变性的基本直觉。群本身描述一组变换，而群作用说明这些变换具体怎样作用在数据、空间或函数上。

机器学习里，如果输入经过某种变换后，输出应该不变或按相同规则变化，就会自然遇到不变量和等变性。这一节只讲基础语言，为后续学习表示论、等变神经网络和几何深度学习做准备。

### 七、机器学习里的代数思维

这一节把前面概念拉回机器学习语境：什么时候应该用代数视角看问题，什么时候不必强行代数化。重点会放在结构化输入、对称性约束、表示学习、图与集合模型、编码和离散状态空间这些场景。

这一节不会把抽象代数包装成所有机器学习问题的通用答案。它更像一份判断指南：当问题真正关心“哪些变换不改变本质”“哪些结构必须被保留”“不同表示是否等价”时，代数语言就会变得有用。
