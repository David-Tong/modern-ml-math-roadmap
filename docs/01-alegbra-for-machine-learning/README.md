# 代数视角：结构、矩阵与变换

机器学习里很多问题表面上是在算数值，背后其实是在处理结构。输入可能是向量、矩阵、集合、图、序列、变换或状态空间；模型要做的，也不只是拟合一个函数，而是在这些对象之间建立可计算、可组合、可分析的关系。

代数视角关心的是：对象之间能做什么运算，变换之间怎样组合，哪些结构在表示变化后仍然保留下来。学代数不是为了多背一些符号，而是为了看懂机器学习中反复出现的线性结构、对称性、可逆变换、低秩结构和稳定计算。

- [抽象代数](01-abstract-algebra/)：从结构视角理解集合上的运算、群、环、域、同态、商结构、作用和不变量。
- [矩阵理论](02-matrix-theory/)：理解特征值、特征向量、正定性、分解、投影和低秩结构。
- [矩阵分析](03-matrix-analysis/)：研究矩阵范数、扰动、条件数和矩阵不等式，为稳定性和误差分析提供工具。
