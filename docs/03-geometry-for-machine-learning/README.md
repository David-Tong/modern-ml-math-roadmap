# 从几何观点看机器学习

机器学习处理的数据通常不只是散落在高维空间里的点。很多时候，数据有形状，参数空间有弯曲，概率分布之间有距离，模型的表示也可能落在某种低维结构上。

几何视角关心的是空间、形状、距离和变换。它帮助我们理解流形假设、表示空间的局部结构、概率分布的几何、优化路径的形状，以及为什么某些模型需要尊重数据本身的空间结构。
